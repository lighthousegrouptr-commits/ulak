Hermes memory files in the Ulak repository are located at /root/ulak/memories/ (not /root/ulak/memory/). The /root/ulak/memory/ directory may not exist. When syncing for Agentic OS, copy from /root/ulak/memories/ to /tmp/hermes-memory/.

Lock files (e.g., MEMORY.md.lock, USER.md.lock) are zero-byte and can be ignored.
