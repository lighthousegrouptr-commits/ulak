# Build Index Pattern — dist/server/index.js Reconstruction (2026-06-03)

## Problem

After `bun run build`, `dist/server/index.js` is generated by Vite with TanStack Start's default handler. This handler does NOT have `/data/live-data.json` KV endpoint or `/app.js` endpoint. The inline `APP_JS` uses `fetch()` which hangs in browser.

## Solution: build-index.cjs

`scripts/build-index.cjs` rebuilds `dist/server/index.js` after each build:

1. Reads current `dist/server/index.js` to extract `DASHBOARD_HTML`
2. Removes all `<script>` tags from HTML
3. Adds `<script src="/app.js"></script>` before `</body>`
4. Writes new `dist/server/index.js` with external APP_JS and KV endpoints

## APP_JS External Serving Pattern

**Never embed APP_JS inline in HTML when HTML is a JS string literal.** The escaping (`\\n`, `\\"`, `\\\\`) causes syntax errors. Instead, serve APP_JS from a separate endpoint:

```js
// Worker code
const APP_JS = "function fmt(n){...} function loadData(){...} loadData();";

export default {
  async fetch(request, env, ctx) {
    const path = new URL(request.url).pathname;
    if (path === "/app.js") {
      return new Response(APP_JS, {
        headers: { "Content-Type": "application/javascript; charset=utf-8" }
      });
    }
    // ... other routes
  }
};
```

HTML contains: `<script src="/app.js"></script>`

## XHR vs fetch in Browser

**Always use synchronous XHR in APP_JS**, not `fetch()`. `fetch()` was observed to never resolve/reject when page is served from Cloudflare Worker (likely caused by Cloudflare's `zaraz` analytics monkey-patching). XHR with `open('GET', url, false)` works reliably.

## Full Deploy Pipeline

```bash
cd /root/code/agentic-os
export PATH="/root/.bun/bin:$PATH"
bun run scripts/aggregate.ts
bun run scripts/transform-live-data.ts
node scripts/build-index.cjs
LEGACY=$(cat src/data/live-data-legacy.json)
wrangler kv key put --binding=LIVE_DATA --remote "live-data" "$LEGACY"
wrangler deploy
```

## Key Files

| File | Purpose |
|---|---|
| `scripts/aggregate.ts` | Scans ~/.claude/, produces `src/data/live-data.json` |
| `scripts/transform-live-data.ts` | Converts new format → legacy format |
| `scripts/build-index.cjs` | Rebuilds `dist/server/index.js` with external APP_JS |
| `src/data/live-data-legacy.json` | Legacy format data (uploaded to KV) |
| `dist/server/index.js` | Worker entry point (rebuilt by build-index.cjs) |
