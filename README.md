# Ulak

Ulak — Lighthouse Group tarafından geliştirilen AI Agent projesi.

## Hakkında

Bu repo, Ulak AI Agent'in konfigürasyonlarını, scriptlerini ve güncellemelerini barındırır.

## Yapı

- `config/` — Konfigürasyon dosyaları
- `scripts/` — Otomasyon scriptleri
- `docs/` — Dokümantasyon
